04 — arquitetura

Liderança Técnica e Arquitetura

  • Migração Serverless → NestJS: Identifiquei o gargalo de escalabilidade (endpoints estourando o limite do Serverless Framework) e liderei a migração para NestJS com arquitetura Hexagonal + DDD — zero downtime — mentorando o time durante toda a transição
  • Migração ElasticBeanstalk → Kubernetes + ArgoCD + Grafana: Coordenei com o time de SRE do cliente, aumentando observabilidade e resiliência (GitOps)
  • Keycloak ponta a ponta: Arquitetei e implementei toda a camada de autenticação JWT/OAuth2/OIDC com controle de permissões granular
  • Mensageria event-driven: SNS/SQS + RabbitMQ com DLQ, retry com backoff e idempotência
  • Pacote NPM compartilhado (GLIC): Cliente GAM + schemas CloudEvents 1.0 reutilizáveis entre serviços
  • CI/CD com GitHub Actions: Pipelines do zero com 1.000+ testes Jest rodando em CI
  • POC Chatbot + RAG (GPT + LangChain): Projetei e desenvolvi do zero — entregue 1 semana antes do prazo para suportar o lançamento de um medicamento de laboratório farmacêutico
