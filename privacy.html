Política de Privacidade — SerginHermes

Última atualização: 02 de outubro de 2026

Esta Política de Privacidade descreve como o aplicativo SerginHermes ("o Aplicativo", "nós") trata as informações acessadas por meio das APIs do Google.

1. Finalidade do aplicativo

O SerginHermes é uma ferramenta de uso pessoal de automação e produtividade, operada exclusivamente pelo seu titular. Ele integra serviços do Google para automatizar tarefas do dia a dia do próprio usuário.

2. Dados acessados

Com a autorização explícita do titular, o Aplicativo pode acessar:

  • Gmail — para ler, organizar e enviar mensagens em nome do titular;
  • Google Calendar — para criar, consultar e gerenciar eventos;
  • Google Tasks — para criar e gerenciar tarefas;
  • Google Drive — para listar e acessar arquivos do titular;
  • Contatos e Planilhas/Docs — quando necessário para as automações solicitadas.

3. Uso e armazenamento

Os dados acessados são utilizados exclusivamente para executar as automações solicitadas pelo titular. Não vendemos, alugamos ou compartilhamos dados com terceiros. Nenhum dado é utilizado para publicidade.

As credenciais de acesso (tokens OAuth) são armazenadas de forma local e segura, exclusivamente no servidor privado do titular, com permissões restritas.

4. Compartilhamento com terceiros

Não compartilhamos dados pessoais com terceiros. O uso de informações recebidas das APIs do Google está em conformidade com a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de uso limitado.

5. Retenção e exclusão

Os dados são retidos apenas pelo tempo necessário à execução das finalidades descritas. O titular pode, a qualquer momento, revogar o acesso do Aplicativo em myaccount.google.com/permissions, o que interrompe imediatamente qualquer acesso.

6. Segurança

Adotamos medidas técnicas razoáveis para proteger as credenciais e os dados, incluindo armazenamento local com permissões restritas e transmissão via HTTPS.
